# 课程方法论与思考方式

这份参考资料来自「账号和人设的定位以及竞争优势」三节课的整理。使用时不要照搬原话，而要吸收其中的判断方式。

## 一、底层思考方式

### 1. 定位不是填表，而是做决策

定位不可能一开始 100% 清晰。它是阶段性方向，不是数学题。

专家判断时要记住：

- 方向可以模糊，但不能无限拖延。
- 如果用户一直在“想清楚再开始”，要提醒他：定位是做出来的，不是想出来的。
- 有 60-70 分方向时，应该进入内容验证。

### 2. 账号定位不是人设

核心公式：

```text
账号定位 = 价值 × 用户 × 人设 × 类型 × 风格
```

人设只是其中一部分。不要让用户一上来就问“我的人设是什么”。

正确顺序：

```text
先价值和用户 -> 再人设和竞争优势 -> 最后类型和风格 -> 用选题验证
```

### 3. 身份只是材料，不是定位

同一个身份可以做很多账号。

例如：

- 产品经理可以讲产品，也可以讲人生规划、职场转型、个人成长系统、育儿方法。
- 宝妈可以讲育儿，也可以讲情绪稳定、家庭关系、女性成长、生活秩序。
- 老师可以讲知识，也可以讲方法论、成长路径、行业避坑。

诊断时不要接受“我是某某，所以我要做某某账号”这种跳跃，要继续追问：

```text
你用这个身份，服务谁，解决什么问题？
```

## 二、价值和用户

### 1. 价值不是大词，而是具体帮助

价值不是“女性成长”“变美”“自律”“AI”“自媒体”这种抽象词。

价值要落成：

```text
某类人在某个阶段遇到某个问题，你帮助他变成更好的状态。
```

例子：

- 不是“女性成长”，而是“刚毕业女生如何摆脱迷茫，建立生活和职业秩序”。
- 不是“变美”，而是“方圆脸女生如何找到适合自己的妆容和发型”。
- 不是“AI 工具”，而是“自媒体人如何用 AI 搭建选题、脚本和复盘工作流”。

### 2. 具体用户比抽象人群重要

不要只写“女性”“宝妈”“年轻人”“自媒体人”。

要写成一个具体的人：

- 她是谁？
- 她处在什么阶段？
- 她每天遇到什么问题？
- 她为什么焦虑？
- 她刷视频时喜欢什么？
- 她讨厌什么表达？
- 她愿意为什么付费？

课程里的判断口径：

```text
像介绍身边闺蜜一样介绍用户。
```

### 3. 形散神不散

账号表面选题可以多样，背后的用户和价值要统一。

如果目标用户是“刚毕业、迷茫、想变好、敏感但励志的年轻女生”，选题可以包括长痘、职场、恋爱、城市选择、和妈妈观念不合、减肥、兴趣变职业。

表面品类不同，但都服务同一个人的生活问题。

专家判断：

- 不要把“品类统一”误认为垂直。
- 真正的垂直是用户垂直和价值垂直。

## 三、人设

### 1. 人设不是身份，而是综合印象

人设不是“我是律师”“我是宝妈”“我是老师”。

人设是观众看你 10 条、30 条、100 条内容后形成的综合印象，包括：

- 专业能力
- 性格气质
- 审美品味
- 情绪基调
- 说话方式
- 做事方式
- 过往经历
- 价值立场
- 和观众的关系
- 面对问题的反应方式

诊断时要问：

```text
观众看你一段时间后，会怎么理解你这个人？
```

### 2. 人设是一种营销，不是自我介绍

“我是短视频老师”只是介绍。

“我能帮普通人突破账号定位和内容流量”才是营销。

判断标准：

```text
我是谁 + 我能为你解决什么 + 我为什么值得你相信
```

### 3. 自媒体是社交关系

粉丝和博主是“最熟悉的陌生人”。

账号不是只交付信息，而是在建立关系。

关系会影响：

- 语气
- 亲密度
- 权威感
- 是否能命令用户
- 是否适合卖高客单
- 内容是否要更多陪伴或更多方法

### 4. 先利他，再埋人设

内容表层要给用户价值，深层再埋人设。

不要一上来只讲自己多厉害。要先解决用户问题，再顺手让用户看到你的经历、判断、立场、性格。

### 5. 单点打透

人设最终可以丰富，但起号早期不要所有标签一起打。

先选一个最容易被记住、最能连接价值、最容易产出选题的人设点，其他面向后续再释放。

### 6. 身教大于言传

不要只说“我专业”“我真诚”“我有审美”。

要展示：

- 你怎么查资料
- 你怎么判断问题
- 你怎么处理失败
- 你怎么做选择
- 你怎么复盘
- 你怎么坚定地生活

强人设不是说教，而是让观众看见“这个人就是这样活着”。

## 四、竞争优势

### 六个方向

```text
正、反、和、跨、借、弱
```

解释：

- 正：找到你能降维服务的人群。
- 反：站在主流市场的反面，回应沉默需求。
- 和：组合两个价值或领域。
- 跨：迁移你过去的能力到新人群。
- 借：借外部资源、案例、身份、平台、现场。
- 弱：把短板、普通经历、失败和现身说法变成力量。

使用原则：

- 先定普通价值，再用六字增强竞争力。
- 不要六个都做，先选一个主优势。
- 如果用户没有明显强资源，重点考虑“跨”“弱”“和”。

## 五、类型和风格

### 1. 先内核，后形式

不要一开始问“我要做口播、vlog、剧情还是图文”。

先问：

- 我服务谁？
- 我解决什么问题？
- 我提供什么价值？
- 我的人设要让别人看到什么？
- 我的竞争优势是什么？

形式只是表达内核的方式。

### 2. 呈现和讲述

短视频表达可以理解成一条光谱：

```text
纯呈现 -> 画面+字幕 -> 场景对话 -> 旁白 vlog -> vlog+口播 -> 情境口播 -> 口播+解释画面 -> 纯口播
```

但不要直接拿这个问用户。用户未必懂形式门槛。

应该用场景问题诊断：

- 对镜头自然吗？
- 能写文案吗？
- 会剪辑吗？
- 能录屏演示吗？
- 有真实生活/工作场景吗？
- 每周能投入多少时间？

### 3. 风格是长出来的

风格不是先设计出来的，而是从这些东西里长出来：

- 你的困难
- 你解决困难的方式
- 你的真实生活
- 你的能力边界
- 你的偶然机会

例子：

- 不敢露脸，可以发展为背影、手部、环境、旁白风格。
- 不会复杂拍摄，可以发展为强语言、强结构、强案例拆解。
- 生活场景特殊，就不要丢掉场景去模仿白墙模板。

### 4. 尊重自己的真实生活

不要总觉得别人的生活才值得拍。

课程里的关键例子：

```text
不是把面馆关掉，回家对白墙拍宠妻日常。
而是拍“面馆里的宠妻日常”。
```

判断口径：

```text
不要从赛道模板里找自己，要从自己的生活里长出赛道。
```

## 六、选题验证

定位写得漂亮没用，必须能长出选题。

验证方式：

1. 设计 2-3 个内容合集。
2. 每个合集 3-5 条选题。
3. 不解释定位，只让别人看选题。
4. 看别人能否判断：你是谁、给谁看、解决什么问题、有什么不同。

如果选题看不出定位，说明定位还没有落地。

## 七、专家诊断时的总体口径

### 1. 不要替用户粉饰

如果用户的想法虚，要说虚。

如果用户的人群大，要压窄。

如果用户的形式成本高，要提醒。

如果用户只是在模仿别人，要指出。

### 2. 给用户更高一级的判断

不要只回答用户表面问题。

例如：

- 用户问风格，可能真正的问题是价值没定。
- 用户问选题，可能真正的问题是用户不具体。
- 用户问人设，可能真正的问题是没有关系定位。
- 用户问赛道，可能真正的问题是没有竞争优势。

### 3. 方案必须能做

一个定位再高级，如果用户做不出来，就不是当前阶段的好方案。

要考虑：

- 用户会不会口播
- 会不会写
- 会不会剪辑
- 有没有时间
- 有没有真实素材
- 有没有案例
- 能不能持续做 30 条

### 4. 推动验证

定位不是一次完成的。

专家要在用户有 60-70 分方向时推动他开拍、测试、复盘，而不是继续打磨概念。
