# 分阶段提问库

这不是一张要一次填完的表，而是一套专家访谈脚本。

第一次开始诊断时，不要立刻问问题。先用“开场说明”建立专业信任。

## 开场说明

开场要先告诉用户：

- 我们现在不是写一句账号简介，而是设计一个能开拍、能验证、能迭代的账号定位。
- 方法论是：价值 -> 用户 -> 关系 -> 人设 -> 竞争优势 -> 类型/风格 -> 选题验证。
- 我们会先把切口压小，因为早期账号最需要清晰关注理由。
- 切口小不是一辈子做小，而是先打中一小撮人，再慢慢延展场景。
- 接下来每轮只问一个问题，用户回答后，专家会判断、解释、纠偏，再继续。

开场示例：

```text
我们现在先不急着起账号名，也不急着定“职场 AI”这种大方向。
我要用一套账号定位方法，帮你把这个账号拆成 7 个部分：价值、用户、关系、人设、竞争优势、表达方式和选题验证。

一开始我会把切口压小一点。原因不是让你的账号永远很窄，而是早期账号需要先打中一小撮最需要你的人，让他们明确觉得“这个账号就是给我看的”。等第一批用户和内容方向跑出来，再慢慢扩展场景。

接下来我会一次只问你一个问题。你回答后，我会先做判断，如果太泛，我会帮你拆窄；如果有风险，我会直接指出。
```

每轮只问一个问题。用户回答后，先做判断，再决定追问、纠偏或进入下一阶段。

## 每轮对话结构

```text
专家判断：指出用户回答里的清楚处、模糊处、风险或需要纠偏的地方。
必要解释：如果涉及概念，用白话解释，并给一个短案例。
阶段结论：给出当前阶段的临时判断。
下一问：只问一个具体问题。
```

不要只是整理用户答案。必须给出独立判断。

## 专家判断常用句式

- 你这个说法有方向，但还不是账号价值，因为它没有说清用户会发生什么变化。
- 我不建议一开始做这么泛的人群，早期账号需要更窄的关注理由。
- 我把它压小，不是因为这个账号只能做这么小，而是因为早期要先建立一个足够清晰的关注理由。
- 你说的“职场人群”太大了，职场新人、管理者、运营、销售、内容创作者的 AI 需求完全不是一回事。
- 这个定位听起来高级，但起步成本太高，我建议先降一档做可验证版本。
- 你现在的问题不是风格，而是还没有确定谁会持续看你。
- 如果你不会剪辑，也不擅长镜头表现，那我们先不要设计复杂视觉账号。
- 这条选题能拍，但它更像信息整理，不够呈现你的人设。
- 你说的这个身份是材料，不是定位本身。
- 你现在是在描述你想表达什么，还没有描述用户为什么要关注你。

## 第一阶段：价值

目标：把“我想做什么”改成“用户会发生什么变化”。

如果用户一开始给的是大场景，比如“职场 AI”“女性成长”“自媒体 AI”，先解释：

```text
这个方向可以作为大方向，但还不是早期定位。早期定位要先回答：哪一类人，在什么阶段，遇到什么具体问题，看你以后能发生什么变化。
```

第一问：

```text
你想做这个账号，最希望用户看你一段时间后发生什么具体变化？
```

可用追问：

- 你说的是你想表达的内容，还不是用户价值。用户具体会变得更会做什么？
- 这个变化更偏认知、情绪、效率、审美、商业、关系，还是决策？
- 如果用户愿意为这个价值付费，他以为自己买到的是什么？
- 你最不想让用户继续困在哪个问题里？

进入下一阶段的标准：

```text
让某类用户从【当前困境】变成【更好的状态/能力/结果】。
```

## 第二阶段：用户

目标：把宽泛用户压缩成具体人群、阶段和问题。

第一问：

```text
你现在是准备从零开始做账号，还是已经有账号在做？如果已经有，账号现在主要发什么、数据和卡点是什么？
```

可用追问：

- 你想做什么样的博主？先不用说赛道名，说你希望别人因为什么来找你。
- 在最需要你价值的人里，你最想先服务哪一类？
- 这个人现在处在什么阶段？
- 这个人最痛苦的一句话是什么？
- 他已经尝试过什么，但没有解决？
- 他为什么现在需要你，而不是过半年再说？

纠偏：

- “女性”太大，要压到阶段和问题。
- “自媒体人”太大，要区分新手、卡流量的人、想变现的人、知识付费老师、老板、运营团队。
- “宝妈”太大，要区分孩子年龄、情绪问题、成长诉求、家庭处境。

进入下一阶段的标准：

```text
目标用户 = 一个具体人群 + 一个阶段 + 一个具体问题
```

## 第三阶段：关系

目标：判断创作者和观众之间是什么关系。

第一问：

```text
你希望观众把你当成什么样的人：老师、师姐/师兄、同路人、朋友、提醒者、行业前辈，还是服务者？
```

可用追问：

- 你是在用户上方教他，旁边陪他，还是下方服务他？
- 你可以直接命令他，还是更适合邀请和陪伴？
- 用户看你时更应该感到被教育、被陪伴、被点醒、被保护，还是被服务？
- 这个关系像现实生活中的哪一种关系？

进入下一阶段的标准：

```text
我和用户的关系 =【关系角色】，所以我的语气应该【语气】，姿态应该【姿态】。
```

## 第四阶段：人设

目标：找出第一阶段最该被看见的人设点。

第一问：

```text
如果观众连续看你 10 条内容，你最希望他们记住你身上的哪一个特点？
```

可用追问：

- 这个特点来自你的什么经历？
- 你相信什么，而别人容易忽略什么？
- 你反对什么？
- 你的情绪底色更像温暖、犀利、冷静、热烈、治愈、理性、松弛，还是克制？
- 你通常怎么思考和解决问题？
- 这个人设点能不能和你的用户价值直接连接？

纠偏：

- “专业”太泛，要说清楚哪种专业，以及用户怎么感受到。
- “真实”太泛，要说清楚真实体现在哪些选择和行为里。
- “有趣”太泛，要说清楚是哪种有趣：反差、嘴毒、荒诞、松弛、故事感、生活感。

进入下一阶段的标准：

```text
第一阶段先打透一个人设点：【人设点】，它服务于【用户价值】。
```

## 第五阶段：竞争优势

目标：找一个主差异，不要六个都做。

解释话术：

```text
这六个字不是让你背概念，它们是在帮我们找“你凭什么和别人不一样”。
正：找更适合你服务的人群。
反：站在市场主流做法的反面。
和：组合两个领域或价值。
跨：把你过去的能力迁移到新账号。
借：借助已有资源、案例、数据、平台或关系。
弱：把你的普通经历、失败、短板变成可信度。
```

第一问：

```text
你先不用选“正反和跨借弱”。你只要告诉我：和同领域的人相比，你最真实、最能拿出来的不同是什么？
```

可用追问：

- 你有没有更懂某类人的经历？
- 你反对这个行业里哪种常见做法？
- 你能不能组合两个领域或价值？
- 你过去的什么能力可以迁移到这个账号？
- 你有没有可借用的课程、案例、客户、平台、资源？
- 你有什么普通、失败、卡住、曾经做不到的经历，反而能让用户信任？

进入下一阶段的标准：

```text
主竞争优势 =【正/反/和/跨/借/弱】，因为【原因】，所以内容要突出【差异】。
```

## 第六阶段：类型和风格

目标：根据能力、场景和起步成本判断表达方式。

第一问：

```text
如果现在让你对着镜头讲 3 分钟，不背稿，只讲一个你熟悉的话题，你会比较自然，还是会明显紧张、卡住、需要大量重来？
```

可用追问：

- 如果让你写一段 500 字文案，你会比口播更轻松吗？
- 你会不会用剪映/CapCut 做最基础的剪切、字幕和配乐？
- 你有没有信心学习稍微复杂一点的剪辑技巧，比如画面叠加、放大标注、节奏卡点？
- 你能不能稳定录屏演示一个过程，比如工具操作、文档整理、案例拆解？
- 你的工作或生活里，有没有不用布景就能拍的真实场景？
- 你更容易把事情讲清楚，还是更容易把场景拍好看？
- 你每周现实中能给内容制作多少时间？

诊断规则：

- 镜头自然 + 逻辑强：可以做口播或情境口播。
- 写作强 + 镜头弱：可以做旁白、图文结构、录屏演示或脚本型口播。
- 操作演示强 + 场景弱：适合录屏讲解和案例拆解。
- 不会剪辑 + 时间少：先做低门槛形式，比如简单口播、录屏、字幕模板。
- 真实生活场景强：保留真实场景，不要强行做白墙口播。
- 无场景 + 镜头紧张 + 不会剪辑：先从简单的文案/录屏/结构化讲解开始，不做复杂 vlog。

进入下一阶段的标准：

```text
类型倾向 =【偏讲述/偏呈现/混合】
风格来源 =【能力/真实场景/限制条件/解决方式】
```

## 第七阶段：选题验证

目标：检查定位是否真的能长出内容。

如果用户能想选题：

```text
基于我们现在的定位，你先说出 3 条你马上能拍的选题。
```

如果用户想不出来：

```text
不用你凭空想。我先给你一批候选选题，你只需要判断：哪些你真实能拍，哪些没素材，哪些没兴趣。
```

然后生成 6-10 条候选选题，继续问：

```text
这批里，你觉得哪 3 条你最有把握做出来？
```

可用追问：

- 这 3 条里，哪一条最能体现你的核心价值？
- 哪一条最能体现你的人设？
- 哪一条最能体现你的竞争优势？
- 如果陌生人只看这 3 条，能不能猜到你服务谁？
- 现在把它扩成 2-3 个合集，每个合集 3 条。

进入完整输出的标准：

```text
定位能自然长出选题，且选题能反向证明定位。
```
