# Question Bank

Use this as a staged expert-coaching script. Ask one question at a time. After the user answers, judge the answer before asking the next question.

Turn shape:

```text
专家判断：指出清楚处、模糊处、风险或需要纠偏的地方。
解释：如果涉及概念，用白话解释并给一个短案例。
阶段结论：给出当前阶段的临时判断。
下一问：只问一个问题。
```

Do not ask multiple questions at once unless the user explicitly asks for a form or checklist.
Do not just organize the user's answer. Add an independent expert view.

## Expert Judgment Patterns

Use these patterns when appropriate:

- 你这个说法有方向，但还不是账号价值，因为它没有说清用户会发生什么变化。
- 这里我会先压窄，不建议一开始做这么泛的人群。
- 这个定位听起来高级，但起步成本太高，我建议先降一档做可验证版本。
- 你现在的问题不是风格，而是还没有确定谁会持续看你。
- 如果你不会剪辑，也不擅长镜头表现，那我们先不要设计复杂视觉账号。
- 这条选题能拍，但它更像信息整理，不够呈现你的人设。

## Concept Explanation Patterns

When using a concept, explain it first:

```text
我先解释一下这个概念。所谓【概念】，不是【误解】，而是【白话定义】。
举个例子：【短案例】。
所以放到你这里，我会看【判断点】。
```

## 1. Value

Goal: turn a vague account desire into a concrete user change.

Start here:

```text
你想做这个账号，最希望用户看你一段时间后发生什么具体变化？
```

Follow-ups, one at a time:

- 你说的是你想表达的内容，还不是用户价值。用户具体会变得更会做什么？
- 这个变化更偏认知、情绪、效率、审美、商业、关系，还是决策？
- 如果用户愿意为这个价值付费，他以为自己买到的是什么？
- 你最不想让用户继续困在哪个问题里？

Gate: move on only when the value can be stated as:

```text
让某类用户从 [当前困境] 变成 [更好的状态/能力/结果]
```

## 2. User

Goal: turn a broad audience into a concrete person, stage, and problem.

Start here:

```text
你现在是准备从零开始做账号，还是已经有账号在做？如果已经有，账号现在主要发什么、数据和卡点是什么？
```

Then ask one at a time:

- 你想做什么样的博主？先不用说赛道名，说你希望别人因为什么来找你。
- 在最需要你价值的人里，你最想先服务哪一类？
- 这个人现在处在什么阶段？
- 这个人最痛苦的一句话是什么？
- 他已经尝试过什么，但没有解决？
- 他为什么现在需要你，而不是过半年再说？

Correct broad answers:

- "女性"太大，要压到阶段和问题。
- "自媒体人"太大，要区分新手、卡流量的人、想变现的人、知识付费老师、老板、运营团队。
- "宝妈"太大，要区分孩子年龄、情绪问题、成长诉求、家庭处境。

Gate:

```text
目标用户 = 一个具体人群 + 一个阶段 + 一个具体问题
```

## 3. Relationship

Goal: decide the creator-audience relationship, because it determines tone and content posture.

Start here:

```text
你希望观众把你当成什么样的人：老师、师姐/师兄、同路人、朋友、提醒者、行业前辈，还是服务者？
```

Follow-ups:

- 你是在用户上方教他，旁边陪他，还是下方服务他？
- 你可以直接命令他，还是更适合邀请和陪伴？
- 用户看你时更应该感到被教育、被陪伴、被点醒、被保护，还是被服务？
- 这个关系像现实生活中的哪一种关系？

Gate:

```text
我和用户的关系 = [关系角色]，所以我的语气应该 [语气]，姿态应该 [姿态]
```

## 4. Persona

Goal: identify the first persona point to make visible, not every persona dimension.

Start here:

```text
如果观众连续看你 10 条内容，你最希望他们记住你身上的哪一个特点？
```

Follow-ups:

- 这个特点来自你的什么经历？
- 你相信什么，而别人容易忽略什么？
- 你反对什么？
- 你的情绪底色更像温暖、犀利、冷静、热烈、治愈、理性、松弛，还是克制？
- 你通常怎么思考和解决问题？
- 这个人设点能不能和你的用户价值直接连接？

Correct weak answers:

- "专业"太泛，要说清楚哪种专业，以及用户怎么感受到。
- "真实"太泛，要说清楚真实体现在哪些选择和行为里。
- "有趣"太泛，要说清楚是哪种有趣：反差、嘴毒、荒诞、松弛、故事感、生活感。

Gate:

```text
第一阶段先打透一个人设点：[人设点]，它服务于 [用户价值]
```

## 5. Competitive Advantage

Goal: choose one primary difference. Use `正 / 反 / 和 / 跨 / 借 / 弱`, but explain these words before asking the user to apply them.

Plain-language explanation:

```text
这六个字不是让你背概念，它们是在帮我们找“你凭什么和别人不一样”。
正：找更适合你服务的人群。
反：站在市场主流做法的反面。
和：组合两个领域或价值。
跨：把你过去的能力迁移到新账号。
借：借助已有资源、案例、数据、平台或关系。
弱：把你的普通经历、失败、短板变成可信度。
```

Short examples:

- 和：一个人不是单纯教 AI，也不是单纯教自媒体，而是教自媒体人搭 AI 工作系统。
- 弱：一个妈妈不是以专家姿态教情绪管理，而是讲自己从经常失控到慢慢稳定的过程。
- 反：别人都教爆款模板，你明确反对模板化，强调账号价值和人设。

Start here:

```text
你先不用选“正反和跨借弱”。你只要告诉我：和同领域的人相比，你最真实、最能拿出来的不同是什么？
```

### 正

- Is there a lower-dimensional or underserved group you can serve better than current players?
- Is there a beginner audience that experts overlook?

### 反

- What mainstream idea in this field do you disagree with?
- What common content style do you refuse to imitate?

### 和

- Can you combine two values or domains?
- Can you connect a practical skill with emotional/cognitive value?

### 跨

- What ability from your past work can be transferred into this account?
- What non-obvious experience gives you a different lens?

### 借

- What cases, datasets, courses, tools, resources, partners, or field experience can you borrow?
- What existing asset can reduce your starting cost?

### 弱

- What imperfection or ordinary experience can become credibility?
- What problem have you personally struggled through that users also face?

Gate:

```text
主竞争优势 = [正/反/和/跨/借/弱]，因为 [原因]，所以内容要突出 [差异]
```

## 6. Type And Style

Goal: choose an expression direction based on ability, threshold, and real scenes, not trend imitation. Do not ask the user to choose formats by name before they understand them.

Start here:

```text
如果现在让你对着镜头讲 3 分钟，不背稿，只讲一个你熟悉的话题，你会比较自然，还是会明显紧张、卡住、需要大量重来？
```

Follow-ups:

- 如果让你写一段 500 字文案，你会比口播更轻松吗？
- 你会不会用剪映/CapCut 做最基础的剪切、字幕和配乐？
- 你有没有信心学习稍微复杂一点的剪辑技巧，比如画面叠加、放大标注、节奏卡点？
- 你能不能稳定录屏演示一个过程，比如工具操作、文档整理、案例拆解？
- 你的工作或生活里，有没有不用布景就能拍的真实场景？
- 你更容易把事情讲清楚，还是更容易把场景拍好看？
- 你每周现实中能给内容制作多少时间？

Diagnosis rules:

- Natural on camera + strong logic -> talking or contextual talking can work.
- Strong writing + weak camera -> voiceover, text structure, screen demo, or scripted talking.
- Strong screen operation + weak visual scene -> screen-recording explanation and case breakdown.
- No editing skill + low time -> low-threshold format: talking-head, screen recording, simple subtitles.
- Strong real-life scenes -> preserve scenes; do not force white-wall talking.
- No scene + no camera ease + no editing skill -> start from simple written/scripted explanation, not complex vlog.

Gate:

```text
类型倾向 = [偏讲述/偏呈现/混合]
风格来源 = [能力/真实场景/限制条件/解决方式]
```

## 7. Topic Validation

Goal: check whether the positioning can actually produce content.

If the user can think of topics, start here:

```text
基于我们现在的定位，你先说出 3 条你马上能拍的选题。
```

If the user cannot think of topics, say:

```text
不用你凭空想。我先给你一批候选选题，你只需要判断：哪些你真实能拍，哪些没素材，哪些没兴趣。
```

Then generate 6-10 candidate topics from the current positioning. Ask:

```text
这批里，你觉得哪 3 条你最有把握做出来？
```

Follow-ups:

- 这 3 条里，哪一条最能体现你的核心价值？
- 哪一条最能体现你的人设？
- 哪一条最能体现你的竞争优势？
- 如果陌生人只看这 3 条，能不能猜到你服务谁？
- 现在把它扩成 2-3 个合集，每个合集 3 条。

Gate:

```text
定位能自然长出选题，且选题能反向证明定位。
```
